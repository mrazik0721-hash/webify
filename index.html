    O mně

    Dělám weby pro malé firmy a živnostníky. Píšu je ručně, aby byl kód čitelný a web rychlý.

    1. ZadáníNejdřív zjistím, co má návštěvník na webu udělat: zavolat, objednat se, spočítat cenu nebo si rezervovat termín.
    2. NávrhVe Figmě nakreslím wireframy a prototyp, abychom se shodli na vzhledu dřív, než začnu programovat.
    3. KódHTML, CSS a JavaScript bez frameworků. Web se přizpůsobí mobilu, tabletu i počítači.
    4. NasazeníKód uložím na GitHub, web nasadím na hosting a předám vám ho funkční.
