Projekty

Weby a e-shopy, které jsem vytvořil pro malé firmy a služby. U každého je náhled, popis a odkaz na živý web.

    Dovednosti

    Front-end

    Sémantické HTML5, CSS3 (Flexbox, Grid, media queries, animace) a vanilla JavaScript v ES6+.

    Back-end a data

    PHP pro administraci a ukládání dat, napojení na Google Sheets, rezervační formuláře.

    Návrh

    Wireframy a prototypy ve Figmě, typografie, barevné systémy a přístupnost.

    Nasazení

    Git a GitHub, hosting, GitHub Pages, Netlify a Vercel.

    O mně

    Programuji weby pro malé firmy a živnostníky. Pracuji ručně, bez zbytečných frameworků, aby byl kód čitelný a web rychlý.

    Každý projekt začínám otázkou, co má návštěvník na webu udělat: zavolat, objednat se, spočítat cenu nebo si rezervovat termín. Podle toho navrhuji strukturu i vzhled.
